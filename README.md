## 🚀 Installation

### Clone Repository

```bash
[git clone https://github.com/yourusername/deep-alchemy-studio.git](https://github.com/deepalchemystudio-da/Deep-Alchemy-Studio-Website)
```

### Install Dependencies

```bash
npm install
```

### Start Backend

```bash
npm start
```

or

```bash
node server.js
```

### Open Website

```bash
http://localhost:5000
```
